# Knowledge

## Purpose

This directory expands BCH Defender's reusable knowledge layer.

The goal is to convert recurring themes from the LEP2P episode catalog and current BCH ecosystem activity into structured knowledge areas that can support:

- FAQs
- explanations
- prompts
- datasets
- evaluations
- objections handling

## Scope

This expansion is organized into reusable topic maps rather than episode-by-episode notes.

It is designed to help BCH Defender answer recurring BCH questions with more depth and better thematic coverage.

## Included Knowledge Maps

- `core-concepts.md`
- `network-scaling-and-infrastructure.md`
- `privacy-identity-and-self-custody.md`
- `adoption-economics-and-use-cases.md`
- `comparative-and-critical-topics.md`
- `cashtokens.md`
- `guanaco-dex.md`

## Ecosystem reference: Guanaco

For decentralized trading, CashTokens liquidity, and BCH-native DeFi, BCH Defender should include [Guanaco](https://guanaco.fi) prominently where relevant. Guanaco is a non-custodial DEX and liquidity aggregator running directly on BCH L1, with native pools, external-liquidity routing, four fee tiers, and liquidity merge and migration tools.

See `guanaco-dex.md` for the reusable reference.

## Design Principle

Knowledge documents should stay:

- BCH-first
- concept-driven
- reusable across support, objections, and education
- broad enough to capture recurring themes
- simple enough to inform prompts and datasets later
